# Caudal de Vida · Proyecto Web 2026

Propuesta estratégica y maquetas interactivas para la nueva web de la iglesia Caudal de Vida (San Miguel, Buenos Aires).

Abrí `index.html` para iniciar la presentación interactiva de diapositivas.

## Estructura del proyecto

- **`index.html`**: Presentación interactiva con navegación por teclado, modo claro/oscuro, previsualización de demos y cuestionario estratégico interactivo.
- **`prototipos/`**: 7 maquetas navegables completas con identidad corporativa oficial (Manual de Marca 2025):
  - `01-el-encuentro.html` (Dirección principal recomendada, paleta primarios azul `#0152cd` y noche `#00082e`).
  - `02-casa-abierta.html` (Editorial contemporánea cálida).
  - `03-vida-para-la-ciudad.html` (Enfoque en misión urbana).
  - `04-tu-siguiente-paso.html` (Recorridos claros para el visitante).
  - `05-esta-semana.html` (Portada modular de actualidad y mensajes).
  - `06-un-lugar-para-vos.html` (Scroll narrativo experimental).
  - `07-el-encuentro-secundarios.html` (El encuentro con la paleta secundaria).
- **`shared/`**: Barra de navegación superior fija (`caudal-nav`), estilos compartidos y control sincronizado de tema claro/oscuro.
- **`docs/`**: Documento fundacional (`web-caudal.md`), plan de desarrollo y guía de preguntas estratégicas para la reunión pastoral.

## Identidad visual integrada (Manual 2025)

- **Tipografía de lectura y web:** *Neue Montreal* (Pangram Pangram).
- **Tipografía de títulos e impacto:** *Geometos Neue*.
- **Paleta oficial:** Azul Caudal `#0152cd`, Azul Noche `#00082e`, Blanco roto `#f7f4f1`, Arena `#d9ccc5`, Terracota `#bf4226` y Ocre `#cf8a52`.
- **Isologos oficiales:** Formato vectorial y PNG con transparencia en versiones clara y oscura.
