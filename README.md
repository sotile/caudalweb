# Caudal de Vida

Propuesta de la nueva web. Abrí `index.html` para la presentación.

- `prototipos/` — seis direcciones. El encuentro es la que se propone.
- `referentes/` — dossier de referencias.
- `docs/` — fuente del cliente, plan, preguntas y automatización.
- `developr.md` — guía para continuar el trabajo.
- `newsite/` — reservada para el sitio de producción.

El ZIP de la presentación queda en la carpeta y no entra al repositorio.
